### 🚀 Featured Projects

#### 🌊 [MIRC — Flood Early-Warning System](https://github.com/1Mii/IES-Project)
*Full-stack platform that predicts and visualizes flood risk to help protect vulnerable populations.*
- **Stack:** React 19 · Spring Boot · Keycloak (OAuth2) · PostgreSQL + PostGIS · Docker Compose · Traefik
- **Highlights:** Real-time sensor data pipeline, risk-calculation microservice, interactive predictive mapping, crowdsourced incident reporting, and role-based dashboards for citizens, Civil Protection, and admins.
- **Why it matters:** End-to-end system design — auth, geospatial data, microservices, and container orchestration in one project.

#### 🛂 [Passport Fraud Detector](https://github.com/brunovieira88/passport-fraud-detector)
*Probabilistic engine that flags fraudulent passports through a multi-layered detection pipeline.*
- **Stack:** MATLAB · Python
- **Algorithms:** Naïve Bayes classification, Counting Bloom Filter (O(1) blacklist lookups), and MinHash similarity to detect forgery networks.
- **Focus:** Applied probability, classification, and similarity detection at scale.

#### 🎵 [UAmplify — Music Streaming Manager](https://github.com/brunovieira88/FDB_UAmplify)
*Desktop application to manage music, albums, playlists, and users for a streaming platform.*
- **Stack:** C# · .NET 8 (Windows Forms) · SQL
- **Highlights:** Role-based access control (Listeners, Artists, Moderators), secure auth, and a relational schema designed for data integrity.

#### ⚙️ [Multithreaded Web Server](https://github.com/brunovieira88/WebServerSO)
*High-performance HTTP server built from scratch in C.*
- **Stack:** C · Pthreads · TCP/IP Sockets
- **Focus:** Concurrency, mutex synchronization, low-level memory management, and network protocols.
